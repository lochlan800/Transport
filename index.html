🛰️ Live data server (optional):

With no server set, this single file runs offline with realistic sample timetables. Add a free live data server (see proxy/ + README.md) to get real train & bus departures across England.

How the live server works The proxy (Cloudflare Worker or local Node) holds your free TransportAPI key and exposes /api/places and /api/departures. The app geocodes your place, then pulls real departures for the modes that support live data (train, bus, tram).
